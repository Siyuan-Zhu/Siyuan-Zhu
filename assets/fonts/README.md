# Editorial fonts

These fonts are bundled so local rendering and GitHub Actions use the same typography.
The original font files are redistributed unmodified under SIL Open Font License 1.1;
their copyright notices and full licenses accompany them.

- Cormorant Garamond (variable roman and italic): https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- IBM Plex Mono Regular (captions and labels): https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Downloaded from the official Google Fonts repository.
The release commit pins the downloaded bytes. Runtime rendering performs no font downloads.
